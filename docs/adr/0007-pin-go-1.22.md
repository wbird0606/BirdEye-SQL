# 0007 — `go.mod` 釘在 `go 1.22`

## 決策

`go.mod` 的 `go` directive 設為 `1.22`，與 `zta-proxy-go`（`module github.com/1150513/zta-proxy`, `go 1.22`）一致。本機安裝的 toolchain 是 1.26.2，用來建置沒問題（`go` directive 是下限）。

## 理由

Phase 2 要把這個 module 以 `require` 引入 `zta-proxy-go`。兩邊語言版本一致可避免 consumer 被迫升級、也讓 CI 環境單純。核心程式碼刻意只用 stdlib，不會用到 1.23+ 的新語法，所以壓在 1.22 沒有成本。若日後 `zta-proxy-go` 升級，這裡跟著升即可。
